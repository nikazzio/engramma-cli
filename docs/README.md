# Documentazione di Engramma

Engramma sincronizza note, regole, skill e memoria di Claude Code tra i tuoi computer. Il programma sta in un repository separato, mentre i dati restano in un archivio Git privato che gestisci tu.

Per la prima installazione segui [Primi passi](getting-started.md). Se hai già un archivio, vai a [Più computer](multi-computer.md) per configurare la seconda postazione.
