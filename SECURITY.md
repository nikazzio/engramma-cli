# Segnalazioni di sicurezza

Non inserire credenziali, memorie private o configurazioni reali nelle issue. Usare dati fittizi e rimuovere indirizzi e percorsi personali dai log.

Le vulnerabilità si segnalano in privato dalla scheda Security del repository ("Report a vulnerability"). Se il canale privato non è disponibile, aprire una issue chiedendo un contatto riservato, senza dettagli sfruttabili o dati personali.

Le correzioni vengono applicate all'ultima versione del programma. Gli archivi privati restano sotto il controllo di chi li usa.
