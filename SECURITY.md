# Segnalazioni di sicurezza

Non inserire credenziali, memorie private o configurazioni reali nelle issue. Usare dati fittizi e rimuovere indirizzi e percorsi personali dai log.

Quando il repository sarà pubblico, usare la segnalazione privata di vulnerabilità nella scheda Security. Se il canale privato non è disponibile, aprire una issue chiedendo un contatto riservato, senza dettagli sfruttabili o dati personali.

Il progetto è in fase di sviluppo: le correzioni vengono applicate alla versione corrente del programma. Gli archivi privati restano sotto il controllo di chi li usa.
